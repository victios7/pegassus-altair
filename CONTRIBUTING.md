# Contributing / Contribuir

## English

1. Keep EN/ES docs in parity when you change behavior.
2. Run `pegassus testsuite` before PRs.
3. Optimizer: fix passes; do not remove optimization levels to “fix” bugs.
4. Preserve library ABI slots 240–255 unless a major version says otherwise.

---

## Español

1. Mantén paridad EN/ES en la docs si cambias comportamiento.
2. Ejecuta `pegassus testsuite` antes de un PR.
3. Optimizador: arregla pasadas; no borres niveles para “arreglar” bugs.
4. Respeta ABI 240–255 salvo major version.

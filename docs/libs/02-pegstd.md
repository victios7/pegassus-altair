# Pegstd library / Librería Pegstd

## English

Path: `lib/pegstd.ir`  
Pure IR. **No** `exec`, no files, no native deps.

Provides: abs/min/max/clamp/sign, pow/fact/gcd/lcm, fib/isqrt/sums, bit ops, rand, strlen/streq/strcat/itoa-style helpers, lerp/percent, etc.

ABI: arguments in **240+**, temps **250–255**. See `docs/libs/01-abi.md`.

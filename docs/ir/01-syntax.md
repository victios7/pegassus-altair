# IR syntax / Sintaxis IR

## English

### Forms
```text
const NAME 123
lab name
push 10
pushs "text"
load 0
store 0
add
jmp name
jz name
jnz name
call name
ret
print
prints
end
halt
include other.ir
```

Comments: `;` to end of line.

`end` and `halt` stop the program. Prefer `jmp main` before libraries.

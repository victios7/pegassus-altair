# VM architecture / Arquitectura de la VM

## English

Pegassus is a classic **stack machine**:

1. Instructions mostly pop arguments from an operand stack and push results.
2. **Locals** provide random-access storage (`load`/`store`).
3. **Control flow** uses absolute label targets resolved at assemble time.
4. **Calls** push a return address onto a separate call stack.

The interpreter maintains: `ip`, operand stack pointer, local frame view, call stack, string pool, optional file/array pools, and a step counter.

Specialized opcodes (`inc_l`, `jle_ln`, …) exist so the optimizer can densify hot loops without changing user-facing IR style.

---

## Español

Pegassus es una **máquina de pila** clásica:

1. Las instrucciones suelen sacar argumentos de la pila y empujar resultados.
2. Los **locales** dan acceso aleatorio (`load`/`store`).
3. El **control de flujo** usa labels resueltas al ensamblar.
4. Los **calls** apilan la dirección de retorno en otra pila.

El intérprete mantiene: `ip`, puntero de pila, locales, pila de calls, pool de strings, pools opcionales y contador de pasos.

Los opcodes especializados (`inc_l`, `jle_ln`, …) permiten densificar bucles calientes sin cambiar el estilo del IR de usuario.

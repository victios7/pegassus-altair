# CLI reference / Referencia CLI

```text
pegassus run <prog.ir>
pegassus --medium|--aggressive|--bare run <prog.ir>
pegassus check|dis|trace|opt <prog.ir>
pegassus asm|build|native [--linux|--windows|--macos] <prog.ir>
pegassus fmt|test|testsuite|repl|clean|examples|cmds|version|help
pegassus --steps N ...
```
